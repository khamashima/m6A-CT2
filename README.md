The track hub files that are used in the paper: Single-cell m6A-CT2 decodes dynamic epitranscriptomic programs that orchestrate cell fates throughout development

Users can view the tracks in the UCSC Genome Browser by selecting “My Data” → “Track Hubs,” clicking “Add Hub,” and entering the URL [https://raw.githubusercontent.com/khamashima/m6A-CT2_hub/main/hub.txt] to browse m6A modification sites across cell types.

The complete hub will be publicly accessible upon publication.
